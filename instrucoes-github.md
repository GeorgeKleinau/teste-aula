# Criar um repositório no GitHub e enviar um arquivo Markdown

Copie o prompt abaixo para um novo chat com acesso ao navegador. Substitua os campos entre colchetes. Para repetir o exemplo desta aula, use `Chrome`, `GeorgeKleinau`, `teste-aula` e `público`.

```text
Abra o GitHub no [navegador] e use a conta já conectada [conta ou organização].

1. Abra o menu de criação do GitHub e selecione New repository. Crie o repositório [nome] com visibilidade [público ou privado]. Use hífens no lugar de espaços no nome. Mantenha as opções de inicialização padrão, salvo se eu pedir outra configuração.
2. Se o repositório já existir, confira o proprietário e a visibilidade e use o repositório existente. Se a conta ou a visibilidade estiver diferente da solicitada, informe a divergência antes de publicar.
3. Crie um arquivo chamado [nome-do-arquivo.md] com o seguinte conteúdo ou objetivo: [descreva o conteúdo ou cole o texto].
4. Envie o arquivo para a raiz do repositório. Use a opção de upload do GitHub e confirme o commit com uma mensagem que descreva o arquivo adicionado. Se já houver um arquivo com esse nome, preserve seu conteúdo até que eu autorize a substituição.
5. Abra o arquivo publicado e confira o nome e o conteúdo. Na resposta, inclua os links diretos do repositório e do arquivo e informe a visibilidade confirmada.
```

Em um repositório vazio, o GitHub oferece a opção **uploading an existing file** na seção **Quick setup**. Em um repositório com arquivos, use **Add file → Upload files**.
